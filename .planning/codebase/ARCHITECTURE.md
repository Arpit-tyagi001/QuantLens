# Architecture

> Generated by /codebase-mapper on 2026-11-12

## Overview
**QuantLens** is a 3-tier quantitative stock-direction prediction application composed of:
1. **ML Pipeline (`ml/`)** — Centralized technical-indicator feature engineering (`build_features`), walk-forward model training (`TimeSeriesSplit` + `StandardScaler` + Platt-calibrated `XGBClassifier`), backtesting, and SHAP explainability.
2. **Backend API (`app/`)** — A FastAPI REST service following a Route → Controller → Service → Repository layered architecture that loads the pre-trained `ml/saved_models/pipeline.joblib`, fetches recent OHLCV data via `yfinance`, caches computed features in an in-memory `TTLCache`, and serves single and multithreaded batch predictions.
3. **Frontend UI (`frontend/`)** — A React + Vite + Tailwind CSS single-page application ("Spatial UI") that submits batch ticker queries to the FastAPI backend and renders `Strong Buy`, `Hold / No Trade`, or `Strong Sell / Short` cards alongside an architecture/backtest summary tab.

## Components

### FastAPI Application Entrypoint
- **Purpose:** Initializes FastAPI app, registers `predict_routes.router`, configures permissive CORS, and exposes `/` health check.
- **Location:** `app/main.py`
- **Dependencies:** `fastapi`, `app.routes.predict_routes`
- **Dependents:** `uvicorn app.main:app`

### API Routes & Schemas
- **Purpose:** Defines `/predict` and `/predict/batch` POST endpoints and Pydantic request models (`PredictRequest`, `BatchPredictRequest`).
- **Location:** `app/routes/predict_routes.py`, `app/schemas/predict_schema.py`
- **Dependencies:** `fastapi`, `pydantic`, `app.controllers.predict_controller`
- **Dependents:** `app/main.py`

### Prediction Controller
- **Purpose:** Extracts request fields (`ticker`, `tickers`) and delegates to `predict_service`.
- **Location:** `app/controllers/predict_controller.py`
- **Dependencies:** `app.services.predict_service`, `app.repository.stock_repository` (unused import)
- **Dependents:** `app/routes/predict_routes.py`

### Prediction Service
- **Purpose:** Loads `ml/saved_models/pipeline.joblib` at module import time, maps `predict_proba` output to directional labels/actions (`>= 0.55` Strong Buy, `<= 0.45` Strong Sell / Short, else Hold / No Trade), and runs batch predictions concurrently via `ThreadPoolExecutor(max_workers=10)`.
- **Location:** `app/services/predict_service.py`
- **Dependencies:** `joblib`, `pandas`, `concurrent.futures`, `app.repository.stock_repository`
- **Dependents:** `app/controllers/predict_controller.py`

### Stock Data Repository
- **Purpose:** Fetches 6 months of daily OHLCV data from `yfinance`, flattens MultiIndex columns if present, computes features via `ml.features.build_features`, extracts the latest row, and caches per-ticker feature DataFrames in `TTLCache(maxsize=100, ttl=300)`.
- **Location:** `app/repository/stock_repository.py`
- **Dependencies:** `yfinance`, `pandas`, `cachetools`, `ml.features`
- **Dependents:** `app/services/predict_service.py`

### Feature Engineering Engine
- **Purpose:** Computes 14 relative/momentum/volatility/lag technical features (`FEATURE_COLS`) from OHLCV data and drops `NaN` rows / replaces `inf` with `0`.
- **Location:** `ml/features.py`
- **Dependencies:** `pandas`, `ta`, `numpy`
- **Dependents:** `ml/train.py`, `app/repository/stock_repository.py`

### Training & Backtesting Pipeline
- **Purpose:** Downloads `AAPL` historical data (`2020-01-01` to `2026-01-01`), builds binary next-day up/down targets, runs 5-fold `TimeSeriesSplit` CV across Logistic Regression, Random Forest, raw XGBoost, and calibrated XGBoost (`CalibratedClassifierCV`), evaluates out-of-sample return/Sharpe/drawdown with `0.001` transaction cost (`ml/backtest.py`), and exports `ml/saved_models/pipeline.joblib`.
- **Location:** `ml/train.py`, `ml/backtest.py`
- **Dependencies:** `yfinance`, `pandas`, `numpy`, `joblib`, `scikit-learn`, `xgboost`, `ml.features`
- **Dependents:** Produces `ml/saved_models/pipeline.joblib` consumed by `app/services/predict_service.py`

### SHAP Explainability Script (Legacy)
- **Purpose:** Loads deprecated `ml/saved_models/model.joblib` and `scaler.joblib` and plots SHAP bar summary for `RELIANCE.NS`.
- **Location:** `ml/shap_analysis.py`
- **Dependencies:** `joblib`, `pandas`, `shap`, `matplotlib`, `yfinance`, `ta`, `numpy`
- **Dependents:** Standalone script

### Frontend Client
- **Purpose:** Provides ticker input (`CommandBar`), batch API calls (`api.js`), prediction cards (`GlassCard`), navigation (`NavBar`), and `Live Analysis` / `Architecture` tabs (`App.jsx`).
- **Location:** `frontend/src/` (`App.jsx`, `main.jsx`, `services/api.js`, `components/*.jsx`)
- **Dependencies:** `react`, `react-dom`, `tailwindcss`
- **Dependents:** Served by Vite / Vercel

## Data Flow
1. **Training (offline):** `ml/train.py` downloads `AAPL` OHLCV -> computes `Target` -> calls `ml.features.build_features` -> splits 80/20 chronologically -> fits `Pipeline(StandardScaler, CalibratedClassifierCV(XGBClassifier))` -> backtests via `ml/backtest.py` -> saves `ml/saved_models/pipeline.joblib`.
2. **Live Inference:** User enters comma-separated tickers in `CommandBar.jsx` -> `App.jsx` calls `fetchBatchPredictions` -> `POST /predict/batch` -> `predict_controller.handle_batch_predict` -> `predict_service.predict_batch` fans out threads -> `stock_repository.get_latest_features` checks `TTLCache` or calls `yfinance.download` + `build_features` -> `pipeline.predict_proba` returns calibrated probability -> `GlassCard.jsx` renders signal/confidence.

## Conventions
- **Naming:** Python `snake_case` modules/functions (`predict_service.py`, `get_latest_features`); React `PascalCase` components (`CommandBar.jsx`, `GlassCard.jsx`, `NavBar.jsx`).
- **Structure:** Layered backend (`routes` -> `controllers` -> `services` -> `repository` + `schemas`); centralized ML features in `ml/features.py` shared between training and serving.
- **Testing:** No automated test suite (`pytest` / `vitest`); only an inline `__main__` smoke check in `ml/backtest.py`.

## Technical Debt
- [ ] **Backtest vs. live threshold mismatch & single-ticker bias:** `ml/train.py` trains only on `AAPL` and backtests at `0.50` binary threshold, while `app/services/predict_service.py` serves `0.55`/`0.45` thresholds (with shorting) for any ticker using unnormalized MACD features.
- [ ] **Non-thread-safe `TTLCache`:** `app/repository/stock_repository.py` accesses `feature_cache` without a `threading.Lock` while `app/services/predict_service.py` runs 10 worker threads.
- [ ] **Unbounded batch requests & missing validation:** `app/schemas/predict_schema.py` has no `max_length` or ticker format validation on `BatchPredictRequest.tickers`.
- [ ] **UTF-16LE & unpinned `requirements.txt`:** `requirements.txt` is UTF-16LE encoded with no pinned package versions, risking deserialization drift for `pipeline.joblib`.
- [ ] **Incomplete intraday candle in live inference:** `app/repository/stock_repository.py` uses `iloc[-1]` during market hours.
- [ ] **Division-by-zero edge cases:** `BB_position` in `ml/features.py` (flat prices) and `sharpe` in `ml/backtest.py` (`returns.std() == 0`).
- [ ] **Error handling gaps:** `/predict` (`app/routes/predict_routes.py`) lacks exception handling; `frontend/src/services/api.js` swallows errors and returns `[]`, making `App.jsx`'s `catch` block unreachable; `frontend/src/components/GlassCard.jsx` hides backend error messages.
- [ ] **Permissive CORS:** `app/main.py` uses `allow_origins=["*"]`.
- [ ] **Stale SHAP script & missing dir guard:** `ml/shap_analysis.py` references deprecated `model.joblib`/`scaler.joblib` and outdated `MA_10`/`MA_50` features; `ml/train.py` writes `ml/data/raw_stock_data.csv` without `os.makedirs("ml/data", exist_ok=True)`.
- [ ] **Frontend polish & config:** Hardcoded Render URL in `frontend/src/services/api.js`, `href="#"` links in `NavBar.jsx`, unused `tailwindcss-animate` classes in `App.jsx`, unused `stock_repository` import in `app/controllers/predict_controller.py`.
- [ ] **No automated tests** across backend, ML, or frontend.
- [ ] **README.md** has broken code fences and a stray `<FollowUp .../>` tag (uncommitted in `git status`).
